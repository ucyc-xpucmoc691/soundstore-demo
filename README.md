# Soundstore.bg — demo prototype (GitHub Pages)

Това е статичен демонстрационен прототип за преглед и обратна връзка. Не е активен онлайн магазин и не обработва реални поръчки, плащания, заявки за лизинг или товарителници. Формите са демонстрационни — не въвеждайте истински лични или платежни данни.

## Какво включва
- `index.html` — целият демо сайт в един файл.
- Responsive дизайн, BG/EN превключване, каталог, категории и марки.
- Демо продуктови страници, количество, количка, примерни складови наличности и 5% отстъпка от 4 броя на един артикул.
- Демо калкулатор за изплащане и визуален пример за Еконт. Банковите ставки са примерни, не са оферти.

## Публикуване чрез GitHub Pages
1. Направете нов **Public** repository, например `soundstore-demo`.
2. Качете `index.html`, `.nojekyll` и `README.md` в основната (root) папка на `main` branch.
3. Отворете **Settings → Pages**.
4. Под **Build and deployment**, изберете **Deploy from a branch**, branch `main`, folder `/(root)`, след това **Save**.
5. GitHub ще покаже публичния URL в същата секция, обикновено `https://USERNAME.github.io/soundstore-demo/`. Публикуването може да отнеме няколко минути.

## Важно
GitHub Pages е само за статичната демо презентация, а не за хостване на реалния търговски магазин. GitHub посочва, че Pages не е предназначен за безплатен хостинг на онлайн бизнес или e-commerce сайт. За реалния WooCommerce магазин ще е необходим отделен хостинг. Репозиторият е публичен, затова всеки може да види качените файлове.
