# Soundstore.bg — demo за преглед

Това е статично HTML демо на Soundstore.bg, подготвено за публикуване чрез GitHub Pages.

## Публикуване с GitHub Pages

1. Влез в GitHub и създай нов repository, например `soundstore-demo`.
2. За най-лесно споделяне избери **Public**. Не качвай пароли, ключове или лични данни.
3. Натисни **Add file → Upload files** и качи `index.html` и `README.md` от тази папка (не качвай само ZIP архива).
4. Натисни **Commit changes**.
5. Отвори **Settings → Pages**.
6. В секцията **Build and deployment** избери **Deploy from a branch**.
7. Избери branch `main` и folder `/(root)`, след което натисни **Save**.
8. Изчакай GitHub Pages да публикува сайта. Адресът ще е:
   `https://ТВОЕТО-ПОТРЕБИТЕЛСКО-ИМЕ.github.io/soundstore-demo/`

Ако repository-то има друго име, използвай него вместо `soundstore-demo` в адреса. Точният адрес се показва и в **Settings → Pages**.

## Важно

- Това е **демо за визуален преглед**, не е работещ production WooCommerce магазин.
- Не се обработват реални плащания и поръчки. Демонстрационните действия в браузъра не се записват в реална база данни.
- Продуктови снимки, които не са вградени в HTML файла, се зареждат от външни сървъри и може да зависят от тяхната достъпност.
- GitHub Pages е за статични файлове; PHP и WooCommerce темата няма да работят като магазин на GitHub Pages. За реална продажба е нужен WordPress хостинг с PHP и база данни.
